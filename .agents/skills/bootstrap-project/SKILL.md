# Bootstrap Project

1. Confirm this is a project copy, not the canonical template.
2. Define product outcome, users, constraints, and non-goals.
3. Create initial requirements and architecture context.
4. Select a stack only when justified by requirements.
5. Configure real unit/contract/integration/lint/type/build/security commands.
6. Add the first executable test and CI path.
7. Mark project metadata active only after verification commands are real.

Do not inherit template-only identity or pretend unconfigured checks are passing.
