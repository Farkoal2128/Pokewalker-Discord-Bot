# Reusable Agent Skills

These skills are project-agnostic workflow playbooks.

Imported/adapted from existing repositories:
- `implement-feature` — bounded planned implementation;
- `drive-feature` — sustained execution across eligible tasks;
- `reconcile-feature-plan` — canonical plan reconciliation;
- `tdd` — RED → GREEN → REFACTOR → VERIFY;
- `contract-change` — deliberate compatibility-aware boundary changes;
- `scoped-review-handoff` — independent review evidence;
- `multi-agent-orchestration` — bounded delegation, ownership, verification, and integration.

Added as generic framework skills:
- `bootstrap-project`;
- `debug-regression`;
- `review-change`;
- `verify-change`.

Skills supplement `AGENTS.md`; they never weaken repository rules or grant extra operational authorization.
The default five-agent topology is documented in `.agents/team/README.md`.
