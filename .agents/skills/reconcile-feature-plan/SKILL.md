# Reconcile Feature Plan

Read current requirements, plan, prompts, decisions, and progress before editing. Maintain one canonical plan per feature. Preserve historical evidence and links.

Trace each change to affected tasks, dependencies, acceptance, rollback, and prompts. Keep approval, implementation, and verification distinct. Editing a plan does not start implementation; use `implement-feature` or `drive-feature` for that.
