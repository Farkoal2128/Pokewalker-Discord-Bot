# Debug Regression

1. Reproduce the defect at the lowest meaningful level.
2. Identify the governing requirement/contract.
3. Add a failing regression test.
4. Narrow the root cause before broad refactoring.
5. Implement the smallest fix.
6. Re-run focused and surrounding regression/contract checks.
7. Record cause, fix, evidence, and any remaining risk.
