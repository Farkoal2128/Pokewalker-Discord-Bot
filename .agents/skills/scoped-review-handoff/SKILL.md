# Scoped Review Handoff

Name the exact reviewed task and boundary. Provide requirement/contract context, before/after behavior, compatibility impact, RED/GREEN evidence, broader checks, rollback, and unresolved risks.

Separate implementation facts from proposals. State what the review does not approve. The implementer may prepare evidence and fix defects but must not approve their own independent-review gate.
