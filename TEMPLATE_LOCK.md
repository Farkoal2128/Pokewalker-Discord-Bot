# Copy-only source

This repository is intended to be the canonical read-only source framework.

Do not implement products directly here. Create an independent project copy first.

Recommended GitHub settings after the initial framework publication:
1. keep the repository private;
2. mark it as a template repository;
3. archive it to make normal repository writes read-only;
4. do not unarchive it for project work;
5. create projects from copies, never by adding this repository as an upstream development remote.

Repository text cannot make owner-level actions impossible. GitHub archival/permissions are the actual server-side enforcement layer.
