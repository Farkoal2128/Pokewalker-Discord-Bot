# Architecture

This template deliberately selects no language, framework, database, cloud, or deployment architecture.

A project created from it should document:
- system context and trust boundaries;
- major components and dependency direction;
- public interfaces and contracts;
- storage ownership and migrations;
- failure/recovery model;
- observability;
- security/privacy constraints;
- deployment topology;
- important tradeoffs.

Record durable decisions in `docs/decisions/`.
