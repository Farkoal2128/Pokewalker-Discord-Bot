# Provenance

This framework was derived from working conventions already used in the owner's repositories and generalized for reuse.

Primary sources inspected:
- `Farkoal2128/QuzMaz` — `.codex/skills/implement-feature`, `drive-feature`, and `reconcile-feature-plan`;
- `Farkoal2128/myAutoclip` — `AGENTS.md`, `skills/tdd`, `skills/contract-change`, and `skills/scoped-review-handoff`.

The copies in this repository are intentionally stack-neutral adaptations. Product names, cloud/provider assumptions, and repository-specific verification commands were removed while preserving the underlying workflow principles.

Do not assume this provenance means future changes should be synchronized back to the source repositories. This repository is a frozen framework source, not an upstream development dependency.
