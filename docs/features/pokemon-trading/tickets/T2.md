**Goal.** Create `pokewalker/services/trading.py`. Mutators require the writer transaction (`_writer`, gyms.py:15-17). `now` comes from `Walker.clock()`.

- **`tradable_reason(pokemon, profile_id, companion_uid, unacknowledged)`** returns `None` or the first of:
  - `not_owned`: missing, not `owned`, or another owner;
  - `deployed`, `favorite`, `companion`;
  - `unacknowledged_catch`: its source encounter has `acknowledged_at IS NULL`.
- **`eligible_page(conn, profile_id, offset)`** returns `(rows, eligible_total, owned_total)`: 10 per page, ordered `caught_at DESC, pokemon_uid`, with the filter in SQL.
- **`open_trade(conn, session, partner_user_id, now)`**, in this order:
  1. `session_owner` → `stale`/`excluded`.
  2. No partner profile in this guild → `partner_not_enrolled`. Same user → `self`. Partner excluded → `partner_unavailable`.
  3. Expire due open trades of either member.
  4. Open trade of this pair → `reopened`.
  5. Either member has another open trade → `busy`/`partner_busy`, with that trade's partner user ID and expiry.
  6. Otherwise insert the trade (uuid4, `expires_at=now+900`, Q7) and sides 0 (caller) and 1 (partner) → `opened`.

  Return `{status, trade_id?, revision?}`.
- **`current(conn, session, now)`** returns the caller's open trade ID or None, expiring it first if due.
- **`offer(conn, session, trade_id, seen_revision, pokemon_uid, now)`**, in this order:
  1. `session_owner`.
  2. A non-participant equals a missing trade → `stale`.
  3. Not open → `ended`; due → `expired`.
  4. Seen revision differs → `changed`.
  5. `storage.detail(caller, uid)` + `tradable_reason` fails → `{status: 'ineligible', reason}`, with no write.
  6. Otherwise set my offer (uid, revision), null both `confirmed_revision`, bump `trades.revision` → `offered`.
- **`cancel(conn, session, trade_id, now)`**: participant-only; open → `cancelled` + `ended_at`, else `ended`/`stale`.
- **C3:** append "Trading service: open, offer, cancel (additive)": statuses and their order; refusals write nothing except lazy expiry.
