**Goal.**

**New `pokewalker/bot/admin_trade_channels.py`:**
- `TradeChannels(app_commands.Group)` with name `trade-channels`, constructed with the `WalkerAdmin` instance so it can reuse `authorize`/`reply`. Its root inherits Manage Server; every handler rechecks it.
- **`add <channel: discord.TextChannel> <reason>`** and **`remove <channel> <reason>`:**
  - Defer ephemerally, then authorize. Exclusion is refused privately.
  - Refuse a channel from another guild ("Choose a channel in this server.") and a stripped-empty reason ("A reason is required.").
  - One writer job: recheck exclusion; `INSERT OR IGNORE` guilds; then `INSERT OR IGNORE` / `DELETE` in `trade_channels`; plus `mod_audit` (target_kind `channel`, action `trade_channels_add|trade_channels_remove`, stripped reason, UTC time), atomically.
  - Replies: "Trade channel added." / "Trade channel removed." Add warns "Missing Send Messages; trade pings will fail until permissions recover." when the bot lacks Send Messages there.
- **`add-all <reason>`:**
  - Mirror channels add-all: `guild.fetch_member` with the same HTTPException and permission refusals.
  - One job: recheck exclusion, then enable each `guild.text_channels` entry where the bot has View Channel **and** Send Messages. Already-enabled channels are untouched and unaudited; each newly enabled channel gets one audit row.
  - Reply: "Enabled N channels; skipped M (no access); K already enabled. Channels created later are not added automatically." ("1 channel" when N is 1).
- **`list`:** a read-only writer job with an exclusion recheck. It lists this guild's channel mentions with `AllowedMentions.none()`, chunked under 2,000 characters, and writes no audit.
