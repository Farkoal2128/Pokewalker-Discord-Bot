**Goal.** `pokewalker/db/migrations/0018_trades.sql`, additive:

- **`trades` table:**
  - `trade_id` PK; `guild_id` REFERENCES guilds ON DELETE CASCADE.
  - `initiator_profile_id`, `partner_profile_id` NOT NULL, each FK `(<col>,guild_id)` → `profiles(profile_id,guild_id)` ON DELETE CASCADE (either deletion removes the trade).
  - `state` CHECK IN (`open`,`completed`,`cancelled`,`expired`), default `open`; `revision` INTEGER NOT NULL DEFAULT 0.
  - `created_at`; `expires_at` with CHECK(expires_at>created_at); `ended_at` NULL.
  - `UNIQUE(trade_id,guild_id)`.
- **`trade_sides` table:**
  - `trade_id`, `guild_id`, `side` CHECK IN (0,1), `profile_id`, `joined_at` REAL NULL.
  - `pokemon_uid` TEXT NULL, no FK (Pokémon die only with their profile); `pokemon_revision`, `confirmed_revision` INTEGER NULL.
  - `open` CHECK IN (0,1), default 0, with CHECK(open=0 OR joined_at IS NOT NULL).
  - PK(trade_id,side); UNIQUE(trade_id,profile_id), which also rules out self-trade.
  - FKs `(trade_id,guild_id)` → trades and `(profile_id,guild_id)` → profiles, both ON DELETE CASCADE.
- **Index:** `UNIQUE INDEX trade_sides_one_open ON trade_sides(profile_id) WHERE open=1`.
- **`trade_channels` table:** `guild_id` NOT NULL REFERENCES guilds ON DELETE CASCADE, `channel_id` NOT NULL, PK(guild_id,channel_id).
- **New profile columns:** `profiles.last_trade_at REAL` and `profiles.last_trade_ping_at REAL` (nullable).
- **Triggers:**
  - `trade_close_sides`: AFTER UPDATE OF state ON trades WHEN NEW.state<>'open' → its sides `open=0`.
  - `pokemon_trade_guard`: BEFORE UPDATE OF profile_id ON pokemon WHEN NEW.profile_id IS NOT OLD.profile_id AND (OLD.state<>'owned' OR OLD.favorite<>0 OR OLD.gym_deployment_id IS NOT NULL OR EXISTS(profiles WHERE companion_uid=OLD.pokemon_uid) OR the old and new profiles are in different guilds) → `RAISE(ABORT,'Pokemon is not tradable')`.
