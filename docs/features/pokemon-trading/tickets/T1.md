**Goal.** Create `pokewalker/db/migrations/0018_trades.sql` (additive):

- **`trades` table:**
  - `trade_id` PK; `guild_id` REFERENCES guilds ON DELETE CASCADE.
  - `initiator_profile_id`, `partner_profile_id` NOT NULL, with CHECK that they differ. Each has `FOREIGN KEY(<col>,guild_id) REFERENCES profiles(profile_id,guild_id) ON DELETE CASCADE`.
  - `state` CHECK IN (`open`,`completed`,`cancelled`,`expired`), default `open`; `revision` INTEGER NOT NULL DEFAULT 0.
  - `created_at`; `expires_at` with CHECK(expires_at>created_at); `ended_at` NULL.
  - `UNIQUE(trade_id,guild_id)`.
- **`trade_sides` table:**
  - `trade_id`, `guild_id`, `side` CHECK IN (0,1), `profile_id`.
  - `pokemon_uid` TEXT NULL with **no FK**: Pokémon die only with their profile, which cascades the trade (`rg -n "DELETE FROM pokemon" pokewalker` → none).
  - `pokemon_revision`, `confirmed_revision` INTEGER NULL; `open` CHECK IN (0,1), default 1.
  - PK(trade_id,side); UNIQUE(trade_id,profile_id).
  - FK(trade_id,guild_id) → trades and FK(profile_id,guild_id) → profiles, both ON DELETE CASCADE.
- **Index:** `UNIQUE INDEX trade_sides_one_open ON trade_sides(profile_id) WHERE open=1`.
- **Eligible P for profile X:** `P.profile_id=X AND state='owned' AND favorite=0 AND gym_deployment_id IS NULL AND NOT EXISTS(profiles WHERE companion_uid=P.pokemon_uid)`.
- **Triggers** (each failing one raises `RAISE(ABORT,'Pokemon is not tradable')`):
  - `trade_close_sides`: AFTER UPDATE OF state ON trades WHEN NEW.state<>'open' → set its sides `open=0`.
  - `trade_offer_guard_insert` and `trade_offer_guard_update`: BEFORE INSERT / BEFORE UPDATE OF pokemon_uid,profile_id ON trade_sides, WHEN NEW.pokemon_uid IS NOT NULL and it is not eligible for NEW.profile_id.
  - `pokemon_trade_guard`: BEFORE UPDATE OF profile_id ON pokemon, WHEN NEW.profile_id IS NOT OLD.profile_id AND (OLD is not owned, is favorite, is deployed, is any companion, or the old and new profiles are in different guilds).
- **Fallout:** at the top of `legacy_schema` (tests/test_receipt_owner.py:46), drop the four triggers, then `trade_sides` and `trades`. Otherwise `DROP COLUMN gym_deployment_id` (:62) and `DROP INDEX profiles_guild_key` (:64) break (trigger-used column, v1.1 PLAN.md:89-90). Nothing else changes there.
