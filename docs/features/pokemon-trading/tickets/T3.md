**Goal.** New `pokewalker/services/trading.py`. Mutators require the writer transaction; `now` comes from `Walker.clock()`. Constants: `TRADE_SECONDS=900`, `CAP_SECONDS=86400`, `PING_SECONDS=600`. **Activity** = `UPDATE trades SET expires_at=MAX(expires_at,:now+900)` (OD9: 15 min idle), run by join and offer.

- **`tradable_reason(identity, pokemon, profile)`**: `not_owned` (None, not `owned`, other owner); else `research.protected_reason(...)` if it is `deployed`/`favorite`/`companion`; else None.
- **`eligible_page(conn, profile_id, offset)`** → `(rows, eligible_total, owned_total)`; 10 per page, `caught_at DESC, pokemon_uid`, filter in SQL.
- **`cap_left(profile, now)`** → remaining seconds or 0.
- **`open_or_join(conn, session, partner_user_id, now, can_ping)`**, in this order:
  1. `session_owner` → `stale`/`excluded`.
  2. `partner_not_enrolled` (none in this guild), `self`, `partner_unavailable` (excluded).
  3. Expire due open trades of either member.
  4. **Pair trade exists:**
     - caller already joined → `reopened`;
     - caller invited: `capped` (with `seconds_left`), `partner_capped`, `busy` (joined elsewhere), else set `joined_at`/`open=1` + activity → `joined`.
  5. **New trade:** `busy` (caller joined elsewhere; its partner ID, for the caller only), `capped`, `partner_capped`, `partner_busy` (no identity revealed); otherwise insert the trade (`expires_at=now+900`), the caller's side (joined, open) and the partner's side (`open=0`) → `opened`.
     - **Ping:** `can_ping` and `last_trade_ping_at` NULL or `<= now-600` → set it to now, `ping='reserved'`; else `'rate_limited'`/`'no_permission'`.

  Return `{status, trade_id?, ping?, seconds_left?}`.
- **`current(conn, session, now)`** → the caller's joined open trade, expiring it first if due, or None.
- **`offer(conn, session, trade_id, pokemon_uid, now)`**: owner check (non-participant/unjoined → `stale`); `ended`/`expired`; `storage.detail` + `tradable_reason` fails → `{status: 'ineligible', reason}`, no write; else set my offer (uid, revision), null both `confirmed_revision`, bump `revision`, activity → `offered`.
- **`cancel(conn, session, trade_id, now)`:** a joined participant moves an open trade to `cancelled` + `ended_at`.
