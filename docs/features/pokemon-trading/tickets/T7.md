**Goal.** In `bot/trade.py`, add `command(bot)`: `@app_commands.command(name='trade', description='Trade a Pokémon with a member of this server')`, `@app_commands.guild_only()`, optional `member: discord.Member`. Defer ephemerally; with no guild → "Use /trade in a server.".

`can_ping` = bot can Send Messages in the channel (checked before the job).

One writer job applies these checks in order:
1. `interaction.channel_id` is not in `trade_channels` for this guild (exact ID; threads never match) → "Trading isn't enabled in this channel. A moderator can enable it with /walker-admin trade-channels add." Nothing is created.
2. Opted out → "Run /walker-account opt-in first".
3. No profile → "Open /walker to enroll before trading."
4. Excluded → `EXCLUDED`.
5. Bot member → "You can't trade with a bot."
6. No member → `trading.current`, else "Use /trade member:@someone to start or join a trade."
7. Otherwise call `trading.open_or_join(..., can_ping)`. Refusals map to text:
   - `self`: "You can't trade with yourself."
   - `partner_not_enrolled`: "They haven't started walking in this server."
   - `partner_unavailable`: "They can't trade right now."
   - `busy`: "You're already in a trade with <@X>; finish or cancel it first."
   - `partner_busy`: "They're in another trade right now."
   - `capped`: "You can trade again in Xh Ym."
   - `partner_capped`: "They can't trade again yet."
8. On success, insert a Walker session (raid.py:30-36 pattern; `expires_at=now + walker.IDLE_SECONDS`; selection `{trade_id, trade_revision}`) and render `render_trade(view(...))`.

**After commit, outside the job, for `opened` + `ping='reserved'`:** `channel.send("<@partner>, <@opener> wants to trade a Pokémon with you. Run /trade and choose them to join.", allowed_mentions=AllowedMentions(everyone=False, roles=False, users=[Object(partner)]))`. On send failure (share.py exception set) the trade stays open and the opener is told privately: "Couldn't ping them; ask them to run /trade."

Opener's screen line: sent → "Pinged them here."; `rate_limited` → "Opened without a ping (one per 10 minutes). Ask them to run /trade."; `no_permission` → "Couldn't ping them; ask them to run /trade."
