**Goal.** One pure module used by the bot, the measurement and the simulation:

- `pokewalker/domain/steps.py`
  - `eligible_words(text) -> list[str]`: drop code blocks, quoted lines (`> `), URLs, mentions
    (`<@…>`, `<#…>`, `<@&…>`), custom emoji (`<a?:name:id>`), Unicode emoji; segment with
    `regex` UAX #29 default word boundaries (`WORD` flag); keep segments with ≥ 2 letters or
    digits.
  - `accept_message(words, at, history, rules) -> Decision`: in D33 order — repetition cap 3
    (case-insensitive), minimum 4, cap 20, cooldown 15 s since the last credited message, 30
    accepted words per rolling 60 s from timestamped buckets (not a token bucket), duplicate
    digest within 1,800 s; then D20 word by word: accepted words in the previous 3,600 s
    (by message time) < 300 → 100 hundredths else 25. Returns `accepted_words`, `awarded_c`,
    `discarded_words`, `reason`. `history` is a small protocol (`accepted_words_since`,
    `last_credit_at`, `seen_digest`) so the bot backs it with SQL and the scripts with memory.
- `scripts/measure_chat_rate.py`: reads JSONL lines `{author_id, channel_id, created_at,
  content, is_bot}`; processes text in memory only; writes per-member-hour totals JSON to a
  local path the owner keeps (never committed) and, with `--summary`, an anonymised markdown
  table (p50/p90/p99 accepted words and awarded steps per active hour; active hour = ≥ 1
  credited message) to `docs/features/pokewalker-bot/measurements/chat-rate-summary.md`.
- `requirements.lock` (P12) and the `pip install -r requirements.lock` step in
  `.github/workflows/verify.yml` after :18 (config, not production).
- `contracts/step-rules.md` (C2).
