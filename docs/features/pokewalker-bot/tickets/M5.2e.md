# M5.2e — `deploy/build_release.sh`: unprivileged, token-free release build

**Tier:** seam (lifecycle; dependency supply chain). Split from M5.2a (review-12 #4);
M5.2a runs it through `runuser -u pokewalker-deploy`. Host steps are G-5's
(PIPELINE.md:73-76).

**Read:** deploy-and-security.md:33 (operator-run script deploying a reviewed commit),
:36 (reviewed releases only; locks give reproducibility, not trust; **build as an
unprivileged deployment identity without the bot token, never root-level pip**), :38-48
(`/opt/pokewalker/releases/<sha>/` owned by root or the deployment account, bot
read/execute only; `/etc/pokewalker` root-managed); `requirements.lock` (hash-pinned,
PLAN P12); **supervisor ruling (Round 12)**: venv build and `pip install` as the deploy
user; root only for unit install, `systemctl` and the release switch.

**Goal.** `deploy/build_release.sh <sha>` (externals by name; tests shim `PATH`):

- **Refuses** (exit 1, nothing built) when `id -u` is 0; when `CREDENTIALS_DIRECTORY`,
  `DISCORD_TOKEN`, any `RESTIC_*` or `BACKUP_MONITOR_URL` is set; or when `<sha>` is not
  a full 40-hex commit present after `git fetch` in the deploy user's clone
  (`git cat-file -e <sha>^{commit}`).
- **Builds in place** at the final path (deploy-and-security.md:53: never relocate a
  venv; review-13 #1): a `releases/<sha>/` with `.complete` is reused untouched; one
  without it (an interrupted build) is deleted first. Then `git archive <sha>` into
  `releases/<sha>/`, `python3 -m venv releases/<sha>/.venv`, `.venv/bin/pip install
  --require-hashes --no-input -r requirements.lock`, and **last** the `.complete`
  marker (fsynced). No rename; M5.2a never uses a release without the marker.
- Release files are world-readable, writable only by the deploy user (the bot cannot
  modify its own code). The script never reads or writes `/etc/pokewalker`,
  `/var/lib/pokewalker` or the `current` link.

**Files.** `deploy/build_release.sh` (1 production script); `tests/test_build_release.py`
(`bash`; fake `id`, `git`, `python3`, `pip` on a temp `PATH` that log calls and fail on
request; paths under `${DEPLOY_ROOT:-}` as in M5.2a).

**Accept.** Tests pass: `test_refuses_root_exit_1`,

`test_refuses_short_or_unknown_sha`,

`test_complete_release_reused_incomplete_one_deleted_and_rebuilt`,
`test_pip_installs_with_require_hashes_from_lockfile`,
