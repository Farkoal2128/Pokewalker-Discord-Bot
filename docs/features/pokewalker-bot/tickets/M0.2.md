**Goal.**

- `content/build/families.py`: family = evolution-chain id; parent edges only from
  `evolves_from_species`; validate same-chain parents, no cycles; depth: root 0, child = parent+1;
  role: root/singleton = base, non-root with children = middle, non-root leaf = final (species
  graph, D54). Family 250 (Phione, Manaphy) has two roots and no edge. Tier per identity, in
  this order: Legendary/Mythical if species `is_legendary` or `is_mythical` (Koraidon/Miraidon
  therefore Legendary, Ultra Beasts not — D57); Evolved if role final and family has ≥ 2
  species; Rare if BST ≥ 500 (non-final or single-stage); Uncommon if middle with BST < 500 or
  base/single with BST 400–499; Common otherwise. BST uses the **identity's own** stats
  (Alolan forms differ). Shedinja is a leaf under Nincada → Evolved (D56). Catch class by tier:
  0.50 / 0.30 / 0.15 / 0.15 / 0.05. Rewards by depth: 3 Candy + 100 Stardust (depth 0 incl.
  single-stage), 5 + 300 (1), 10 + 500 (2); Legendary/Mythical 10 + 500 (D40a).
- `content/build/stats.py`: GO-style base stats from main-series stats with
  `round(x) = floor(x + 0.5)`: `q = 1 + (Speed − 75)/500`, `A = round(round(2(7·AH+AL)/8)·q)`,
  `D = round(round(2(5·DH+3·DL)/8)·q)`, `S = floor(1.75·HP + 50)`. No GO exceptions (D39). Each
  record is labelled `stats_source: "derived-d39"`. Stats and BST are derived for every
  identity **and** every attached gender variety (M0.1); the identity's tier uses the male
  default's BST (D53).
