# M5.2a — `deploy/deploy.sh`: root orchestration, identities, first deploy, rollback

**Tier:** seam (credentials; lifecycle). Split from M5.2 (review-8 #14); templates in
M5.2d, build in M5.2e; host steps are G-5's (PIPELINE.md:73-76).

**Read:** ADR 0001:49-50, :82-84; process-and-runtime.md:44-52, :57-61;
deploy-and-security.md:36 (token-free unprivileged build), :38-48, :50-58 (rollback
checks schema compatibility first; DB restore only by explicit decision); review-11 #6,
review-12 #4, review-13 #2; supervisor rulings (Rounds 12-13). Code: config.py:45-55;
client.py:209-213 (`check-config`); db/__init__.py:33-45 (supported schema = migration
count; newer DB refused; migrations at start); M4.5b ready file; M5.2c backup exits;
M5.2e `.complete`.

**Goal.** `deploy/deploy.sh <sha> [--restore-db <snapshot>]`, run as root; paths under
`${DEPLOY_ROOT:-}`; externals by name (tests shim `PATH`); nothing inherited from the
operator's shell.

- **Identities.** Build: `runuser -u pokewalker-deploy -- env -i PATH="$PATH"
  HOME=/var/lib/pokewalker-deploy build_release.sh <sha>` (M5.2e). `check-config`:
  `systemd-run --wait --pipe --collect -p User=pokewalker` with the bot unit's
  `EnvironmentFile=` and `LoadCredential=`. Root does only unit install (`install` +
  `daemon-reload`), `systemctl`, the `current` switch, and `backup.sh` as in its unit
  (`env -i`, `backup.env` keys, `STATE_DIRECTORY=/var/lib/pokewalker-backup`, `umask
  077`). Ready file: `/run/pokewalker/ready`.
- **First deploy:** no `current` link **and** no DB → no stop, backup or rollback;
  readiness timeout → stop, exit 20. Exactly one of them present → refuse, exit 10.
- **Sequence:** lock; build; `check-config` (either failing before the service is
  touched → exit 10; a release without M5.2e's `.complete` marker is never used); stop;
  `backup.sh`: continue **only** on 0, 2 or 3 (2/3 warn); **1 or any other status** →
  restart the unchanged previous release, wait for ready, exit 40; install the release's
  units and switch `current`; start; wait ≤ 60 s for the ready file; print the manifest
  hash and, only if it changed, the `sync-commands` line.
- **Rollback** on readiness timeout: stop, then **check schema compatibility**: DB
  `PRAGMA user_version` (`sqlite3 -readonly`) vs the previous release's migration count.
  Compatible → previous units and symlink, start, wait (exit 20; exit 30 if that fails).
  DB newer → never start the old release; stay stopped, print this run's snapshot path,
  exit 50 (recovery: rerun with `--restore-db`). The DB is restored **only** with
  `--restore-db`. Token never in arguments or output.
