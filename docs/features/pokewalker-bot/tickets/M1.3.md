**Goal.** Every function takes `rng: random.Random` and tables from `content.balance` /
the artifact; no I/O, no time reads.

- `pokewalker/domain/encounters.py`
  - `roll_tier(route_pools, chances, rng)`: roll Legendary at exactly 1 % first; otherwise
    roll among non-legendary tiers; if the rolled tier is empty on this route, spread its chance
    proportionally over the route's other non-empty non-legendary tiers (D50).
  - `pick_identity(pool, weights, rng)`: proportional to route weight; weight 0 is ineligible;
    Legendary tier is uniform over all Legendary/Mythical identities, ignoring the route.
  - `roll_gender(identity, rng) -> (gender, variety)`: PokéAPI `gender_rate` (−1 genderless;
    rate/8 female); Indeedee/Basculegion/Oinkologne roll 50/50 and return that gender's
    variety record from `gender_varieties` — its own `pokemon_id`, base stats and sprite keys
    (D53); other identities return their own record.
  - `roll_shiny(rng, lure_active)`: 1/256, ×4 when a lure was active at generation.
  - `roll_level_ivs(rng)`: level 1–20 (`level_x2` 2–40), IVs 0–15; `starter_rolls(rng)`:
    level 10, IVs 10–15.
  - `generate(identity_pools, route, lure_active, rng) -> EncounterSpec` (frozen dataclass
    carrying the chosen variety's `pokemon_id`, base stats and sprite keys, so CP, catch and
    rendering never look the male default up again).
- `pokewalker/domain/cp.py`: `cpm(level_x2)` from `cpm.json`; `cp(base, ivs, level_x2) =
  max(10, floor((A+a)·sqrt(D+d)·sqrt(S+s)·m²/10))`; `hp = max(10, floor((S+s)·m))`;
  `appraisal(ivs) -> 0..4` stars (0–22, 23–29, 30–36, 37–44, 45); `catch_probability(bcr,
  level_x2, ball, berry) = 1 − (1 − clamp(bcr/(2·m), 0, 1))^(ball·berry)`;
  `flees_after_failure(tier, shiny, rng)` (P5).
