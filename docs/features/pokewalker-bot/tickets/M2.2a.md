**Goal.**

- Migration `0003_receipt_owner.sql`, in this order:
  1. `ALTER TABLE action_receipts ADD COLUMN profile_id TEXT REFERENCES profiles ON DELETE
     CASCADE;` + index `action_receipts(profile_id)`.
  2. **Backfill** every existing receipt: by ledger line (`profile_id` of any
     `resource_ledger` row with `receipt_key = key`); by encounter (`key LIKE 'throw:' ||
     encounter_id || ':%' OR key LIKE 'run:' || encounter_id || ':%'` → its profile); by
     enrollment (`key = 'enroll:' || guild_id || ':' || user_id` → that profile).
  3. **Unattributable**: a receipt still NULL after step 2 belongs to a profile or
     encounter that no longer exists (only `enroll|throw|run` exist before 0003) →
     `DELETE` it. Any other action name at NULL → `RAISE(ABORT)` (never guess an owner).
- `with_receipt(conn, key, action, compute, *, profile_id=None)` stores the owner on
  insert; replay unchanged. Three one-line producer edits: `run` (walker.py:344) and
  `throw` (catching.py:139) pass `session["profile_id"]`; `enroll` (profiles.py:114) sets
  it after `compute` created the profile (`UPDATE … WHERE key=?`).
- C3 appended (`contracts/persisted-state.md`): every receipt for an action on a profile
  carries that `profile_id` and disappears with it; process receipts (`reset:<marker_id>`
  audit dedupe, `restart:*`) carry NULL and hold no player data beyond marker-log ids.
- **Intentional test updates** (AGENTS.md:29-32; review-11 #4): test_db.py:75
  (`user_version == 2`) and :88 (sets 3, expects refusal) derive `supported` = the
  migration count under `pokewalker.db.MIGRATIONS` and assert `== supported` / set
  `supported + 1`; apply-once and newer-schema refusal stay; later migrations need no
  test_db.py edit.
