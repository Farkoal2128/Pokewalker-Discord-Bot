# M0.1 — PokéAPI fetch at the D51 pin, graph load, exact filter

**Tier:** seam (route/encounter tables; PIPELINE.md:13)

**Read:** README.md:204-216 (D51–D52), :241-242 (D58); research pokeapi-forms.md:543-551 (filter
steps 1–7), :70-72 (57 regional varieties), :516-524 (pinning and build checks); ADR 0001:43-45;
PIPELINE.md:64-66; PLAN §4.1 P11.

**Goal.** Two stdlib-only modules.

- `content/build/fetch.py`: download the CSVs below from
  `https://raw.githubusercontent.com/PokeAPI/pokeapi/e5b79b2e15d7c50735a945936afd4cd1cfd94eae/data/v2/csv/<name>.csv`
  into `build/pokeapi/e5b79b2e/` (gitignored); record sha256 per file; refuse to overwrite a file
  whose hash differs from a recorded one. CSVs: `pokemon_species`, `pokemon`, `pokemon_forms`,
  `pokemon_stats`, `pokemon_types`, `pokemon_form_types`, `pokemon_species_names`,
  `pokemon_form_names`, `types`, `pokemon_habitats`, `pokemon_evolution`, `stats`; optionally
  `pokemon_sprites`, `pokemon_form_sprites` (existence UNVERIFIED, PLAN P7 — report, do not fail).
- `content/build/graph.py`: join species → varieties → forms by foreign key; apply filter steps
  1–4 of pokeapi-forms.md:545-548 (exclude `is_mega`/`is_battle_only`, `mega`/`gmax`/`primal`/
  `eternamax` tokens incl. the Eternamax false flag Pokémon 10190/form 10359; keep each species
  default; add the 57 regional varieties by exact `form_name` set). Then apply D52 as data:
  default-only groups dropped; separate encounters added for Wormadam cloaks, Oricorio styles,
  Pumpkaboo/Gourgeist sizes, Bloodmoon Ursaluna; Lycanroc/Urshifu non-default forms excluded from
  encounters (evolution branches, v1.1); Minior = Meteor default; Arceus Unknown form 10057
  quarantined (D58). For Indeedee, Basculegion and Oinkologne the female variety is attached
  to the species-default identity as `gender_varieties`, not emitted as a separate identity
  (D53). Output: list of identities `{identity_id, species_id, pokemon_id, form_id, kind:
  default|regional|form, types[], name_en, gender_varieties?}` plus an `excluded`/`pending`
  report. Any identity or attached variety missing six stats or a type is a build error.

**Files.** `content/build/__init__.py`, `content/build/fetch.py`, `content/build/graph.py`
(2 production files), `.gitignore` (new: `build/`, `.venv/`, `__pycache__/`, `*.sqlite3*`),
`tests/test_content_graph.py`, `tests/fixtures/pokeapi_mini/*.csv` (hand-made rows: a plain
