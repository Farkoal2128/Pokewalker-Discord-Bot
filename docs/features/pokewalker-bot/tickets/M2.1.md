**Goal.**

- `pokewalker/services/storage.py`: `identify(content, pokemon) -> (identity, sprite_url)`
  (lift the duplicated lookup from walker.py:158-163/:269-273; walker.py calls it, behaviour
  unchanged); `page(conn, profile_id, offset) -> (rows, total)` — `state='owned'`,
  `ORDER BY caught_at DESC, pokemon_uid`, 10 per page; `detail(conn, profile_id, uid)`;

  row does not name them; research :50 is a recommendation).

  `self.handlers.update(storage.handlers(self))` in `Walker.__init__` (2 wiring lines).
  Page: text lines `#n Name · CP · shiny · fav` plus `n/250`, no image; Prev/Next
  (disabled at bounds), open select, Back. Details: name, form, gender sign, shiny text,
  CP, HP, appraisal stars, types, caught date, favorite state; sprite as embed image
  (exact key or none); Favorite/Unfavorite, Back; second row of disabled placeholders
  Send for research (M2.2), Power up (M2.3), Set companion (M2.4), Share (M4.4).

  state["available"]`, `available = set(walker.handlers)`) so later rows need no
  screens.py edit; walker.py:381-383's Storage button becomes a live `storage` action.
