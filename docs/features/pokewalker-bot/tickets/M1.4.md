**Goal.**

- `pokewalker/services/profiles.py`
  - `get_profile(conn, guild_id, user_id)`.
  - `restrictions(conn, guild_id, user_id) -> Restrictions(paused: bool, paused_until:
    datetime|None, excluded: bool, share_banned: bool)` — independent fields from the
    `restrictions` table keyed by (guild_id, user_id). `paused=True, paused_until=None` is an
    indefinite pause; a timed pause reads `paused=False` once `until` has passed. Every
    mutating transaction in later rows calls this inside its own `BEGIN IMMEDIATE`.
  - `enroll(conn, guild_id, user_id, starter_species_id, content, rng, now)` — one writer job
    under `with_receipt(key=f"enroll:{guild_id}:{user_id}")`: refuse if `excluded` (a
    restriction row needs no profile, so delete-then-re-enroll is covered), if a profile
    exists, or if the species is not a starter; create `profiles` (uuid4, route Refreshing
    Field); create the starter `pokemon` (origin `starter`, `starter_rolls`, gender from
    `gender_rate`, shiny false, favorite true) and set it as companion; `inventory` 30 Poké
    Balls, 5 Razz Berries; `pokedex` seen+caught; queue the first encounter via
    `domain.encounters.generate` on the default route (D26); return the profile.
  - `queue_size(conn, profile_id)` counts `state IN ('queued','revealed')` — the one
    occupancy definition (M1.5, M1.7, M1.8).
  - `channel_policy(conn, guild_id, channel_id, parent_id)` (threads inherit the parent, P2).
- `pokewalker/bot/admin_channels.py`: `/walker-admin channels add <channel> <reason> [count]
  [react]`, `remove <channel> <reason>`, `list`; `default_member_permissions=manage_guild`,
  guild-only, ephemeral; the handler rechecks `guild_permissions.manage_guild`. `add`/`remove`
  are one writer job that writes the policy row and a `mod_audit` entry (actor, target_kind
  `channel`, target_id, action, reason, time) together; a missing reason is refused by the
  command schema. `list` is read-only and unaudited. `add` warns when `ADD_REACTIONS`/
  `READ_MESSAGE_HISTORY` are missing (reactions then skip, P2). Appends to C5.
