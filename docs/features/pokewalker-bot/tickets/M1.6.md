**Tier:** seam (slash commands and interaction responses; persisted state; abuse controls)

**Goal.**

- `pokewalker/bot/walker.py`
  - `/walker` (guild-only): `defer(ephemeral=True)`; read `restrictions`; **excluded** →
    explain that only `/walker-account privacy`/`delete-data` work; no session, no change.
    Otherwise insert `sessions(session_id uuid, guild_id, user_id, profile_id or NULL,
    revision=0, expires_at=now+15 min)`. With a profile: one writer job sets
    `desired='remove'` on the profile's remaining `reactions` rows (completed ones are
    retired by M1.4b, so this is pending work only) and after commit calls
    `reconcile_reaction` for each (D3: opening `/walker` clears ❗); then M1.9's
    unacknowledged-result check runs before home is rendered. Without a profile: onboarding.
  - Router: the `DynamicItem` from M1.2 parses `pw:v1:<session>:<rev>:<action>`, loads the
    session, requires `interaction.user.id == session.user_id` and `guild_id ==
    session.guild_id` (else ephemeral "not yours", no state change), checks expiry and
    revision (stale → "reopen `/walker`", no state change), re-reads `restrictions` and
    refuses every action for an excluded user, then dispatches to a handler by name. Paused
    users still resolve encounters (D31). Handlers in this row: `home`,
    `onboard_gen`, `onboard_pick`, `onboard_confirm`, `open_encounter` (M1.7). Each successful
    handler bumps `revision`; `onboard_confirm` also attaches the new `profile_id` to the
    session.
  - Onboarding: explain the loop in ≤ 6 lines; generation select (9) → starter select (3) →
    confirm → `services.profiles.enroll` (receipt; refuses excluded) → home.
  - Home: companion name/CP with its sprite as embed thumbnail (D49; `null` → none), queue
    `n/3` using M1.4 `queue_size`, encounter meter bar, paused notice with `until`, buttons
    `Open encounter` (disabled when queue empty), disabled placeholders for
    Storage/Bag/Pokédex/Route (enabled by M2/M3).
- `pokewalker/bot/screens.py`: pure render functions `(state) -> dict(embed=…, view=…)`; no
  DB access; sprite URL from the artifact. Append `/walker` to `contracts/discord-commands.md`.
