# M1.2 — Bot process: config, token, intents, lifecycle, command sync

**Tier:** seam (bot token and intents; gateway; verification/config contract)

**Read:** ADR 0001:26-35 (library, intents, cache off, layers); research
process-and-runtime.md:57-63 (credentials), :131 (drain ≤ 20 s, exit 75);
deploy-and-security.md:62-72 (shutdown, command registration as a deployment step);
discord-interactions.md:23-26 (persistent views, dynamic items); intents research:56, :60-61;
monitoring-and-admin.md:58 (owner-id allowlist); PLAN §4.1 P10, P11, P13; §4.2 C5.

**Goal.**

- `pokewalker/config.py`: `Settings.from_env()` reads `POKEWALKER_DB_PATH`,
  `POKEWALKER_CONTENT_PATH` (default `content/artifact/content.json`),
  `POKEWALKER_OWNER_IDS` (comma list), `POKEWALKER_ALLOW_UNPATCHED_SQLITE`,
  `POKEWALKER_DEV_GUILD_ID`; token from `$CREDENTIALS_DIRECTORY/discord_token` (stripped),
  else `DISCORD_TOKEN` with a WARNING. The token is a `Secret` whose `repr`/`str` is
  `***`; `Settings` never logs it.
- `pokewalker/bot/client.py`: `WalkerBot(discord.Client)` with intents exactly
  `guilds | guild_messages | message_content`, `max_messages=None`, an
  `app_commands.CommandTree`, `setup_hook` that: opens the DB (M1.1), loads the artifact and
  refuses to start if its hash ≠ `content/manifest.json`, starts the writer, registers one
  `DynamicItem` matching `^pw:v1:(?P<session>[0-9a-f-]+):(?P<rev>\d+):(?P<action>[a-z_]+)$`
  (routing is filled by M1.6). One idempotent `drain()` on SIGTERM/SIGINT: stop admitting
  messages, wait for the writer queue to empty (≤ 20 s, injected clock), close Discord and DB,
  exit 0; `restart()` runs the same drain then exits 75 (used by M4.5). Commands sync only via
  the CLI below, never on `on_ready`.
- `pokewalker/__main__.py` (≤ 30-line shim): `run`, `sync-commands --guild <id> | --global`
  (prints the manifest hash and asks for `--yes`), `check-config`.
- `contracts/discord-commands.md` (C5): start with the custom_id grammar, the intent set, the
  rule "guild-only commands, ephemeral replies, runtime permission recheck"; later rows append
  their commands.

**Files.** `pokewalker/config.py`, `pokewalker/bot/__init__.py`, `pokewalker/bot/client.py`
(2 production files + package init), `pokewalker/__main__.py` (shim), `contracts/discord-commands.md`,
`tests/test_config.py`, `tests/test_client_lifecycle.py` (no network; discord.py objects are
constructed but never connected).
