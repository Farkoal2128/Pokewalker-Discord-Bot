**Goal.** `pokewalker/services/catching.py` + handlers in `walker.py`:

- `throw(conn, encounter_id, session, expected_revision, rng, now)` — one writer job:
  1. Under `BEGIN IMMEDIATE` load the encounter; require owner = session profile,
     `restrictions.excluded` false, `state='revealed'`, `revision == expected_revision`
     (which also fixes the attempt ordinal). Any failed check returns the **persisted current
     state** without spending: a terminal encounter returns its caught/fled/ran result (so a
     second click, a second screen, or a Throw after a Run on another screen all see the same
     outcome); an exclusion returns `excluded`.
  2. Storage full (owned `pokemon` count ≥ 250) → return `storage_full`, spend nothing.
  3. Require ≥ 1 of the selected ball and, if a berry is selected, ≥ 1 of it; decrement one
     ball and at most one berry. The berry stays selected like the ball (owner decision
     2026-11-12, superseding "clear the berry selection"); when it runs out the throw is
     refused with `no_berry` until the player picks another berry or None.
  4. `p = catch_probability(bcr, level_x2, ball, berry)`; roll once; insert
     `catch_attempts(encounter_id, ordinal, ball, berry, p, success, fled)`; bump
     `attempt_ordinal` and `revision`.
  5. Success: insert `pokemon` (origin `catch`, `source_encounter_id` unique, frozen rolls,
     favorite false), `state='caught'`, `pokedex.caught_at`, Candy by depth (Pinap ×2, Silver
     `floor(7b/3)`) and Stardust per D40a through the ledger — all in this job.
  6. Failure: `flees_after_failure(tier, shiny, rng)` → `state='fled'` or stay `revealed`.
  Return a frozen result for the renderer; the Discord edit happens after commit. If it fails,
  `/walker` reopens a still-`revealed` encounter (M1.7) or M1.9 surfaces the unacknowledged
  terminal result.
- `master_ball`: first press renders a confirmation naming the Pokémon; confirm → the same
  job with `guaranteed=True`: identical checks in step 1 plus storage, consume the Master Ball
  (rare pocket 1 → 0), no probability roll, never flee.
- Result screen: caught (sprite, CP, appraisal stars, Candy/Stardust gained; `Done` → `ack`
  (M1.9); `Share` placeholder disabled until M4.4), fled, or "it broke free" with bag counts.
