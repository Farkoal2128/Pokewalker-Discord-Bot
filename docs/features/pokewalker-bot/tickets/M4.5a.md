**Goal.**

- `pokewalker/config.py` (wiring, 2 fields): `POKEWALKER_ADMIN_GUILD_ID` (unset →
  `/admin` not registered, logged; never global) and `POKEWALKER_RELEASE` (default `dev`).
- `pokewalker/bot/client.py`: `scope_commands(guild)` = global commands + commands
  registered to that guild; `command_manifest_hash` and `sync_commands` use it;
  `sync_commands(guild)` always `copy_global_to(guild)` before `sync`. `/admin` is
  added with `guild=admin_guild_id`.
- `pokewalker/bot/admin.py`: group `/admin`, guild-only, ephemeral.
  - `authorize(interaction)` on every subcommand and the restart confirmation:
    `guild_id == admin_guild_id`, `user.id in owner_ids`, **and** not excluded in that
    guild (as admin_channels.py:23-26); roles do not count.
  - `status`: release, uptime, `latency`, `is_ready()`, writer queue depth and
    closed/failure flag, guild count, messages received/credited/rejected since start
    (two counter increments in `messages.on_message`, wiring), manifest hash prefix.
    No token, env, paths or message text.
  - `errors`: a `logging.Handler` attached at setup feeding `deque(maxlen=10)` of
    `{time, logger, level, exception type}` only.
  - `restart`: first call stores `(owner_id, expires_at = now + 60)` in memory; a second
    call within 60 s by the same owner runs one writer job: refuse if any receipt with
    `action='restart'` has `created_at > now − 300` (durable cooldown), else
    `with_receipt(f"restart:{now}", "restart", …, profile_id=None)`; then ack
    "restarting" and `await bot.restart()`.
- Append C5 (scopes: global = gameplay commands; admin guild = global + `/admin`).
