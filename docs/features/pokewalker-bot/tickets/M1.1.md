# M1.1 — DB foundation: WAL, version check, migrations, single writer, receipts

**Tier:** seam (persisted player state and migrations)

**Read:** ADR 0001:36-42 (SQLite settings, writer, version floor); research
storage-and-data-model.md:56-74 (entity sketch), :78-85 (transaction rules);
reliability-and-data.md:57; README.md:33 (D10 key), :60 (D28: profile ids are random UUIDs);
PLAN §3.1 toolchain note, §4.1 P9, P10; §4.2 C3.

**Goal.**

- `pokewalker/db/__init__.py`
  - `check_sqlite_version(v) -> bool`: `v >= (3,51,3)` or `(3,50,7) <= v < (3,51,0)` or
    `(3,44,6) <= v < (3,45,0)` (ADR wording; implementer confirms against sqlite.org release
    notes in RED and records the result).
  - `open_db(path, *, allow_unpatched=False)`: refuses on a failing check unless
    `allow_unpatched`, which logs a WARNING; applies `journal_mode=WAL`, `synchronous=FULL`,
    `secure_delete=ON`, `foreign_keys=ON`, `busy_timeout=5000`; runs migrations from
    `pokewalker/db/migrations/NNNN_*.sql` in order, tracked by `PRAGMA user_version`.
  - `Writer`: one asyncio task consuming a queue of jobs `async fn(conn) -> T`; each job runs
    inside `BEGIN IMMEDIATE … COMMIT` on the single write connection, rollback on exception,
    result/exception returned to the awaiting caller; `await writer.run(fn)`. A separate
    read-only aiosqlite connection serves screens.
  - `with_receipt(conn, key, action, compute)`: if `action_receipts.key` exists, return its
    stored result; else run `compute`, insert the receipt and its `resource_ledger` lines in
    the same transaction. This is the "applies once" primitive every later row uses.
- `pokewalker/db/migrations/0001_core.sql` (full columns in C3): `guilds`, `guild_channels`
  (count_steps, react), `profiles` (uuid PK, `UNIQUE(guild_id,user_id)`, route, companion,
  stardust, three meters in hundredths, last_checkin_at), `restrictions` (keyed by
  guild+user, D28), `mod_audit` (actor, target_kind `user|channel`, target_id, action, reason,
  created_at), `step_events` (message_id PK, counts, awarded_c, reason), `encounters` (frozen
  rolls, tier, route, lure id, state, attempt_ordinal, revision, content_version,
  `acknowledged_at NULL`), `catch_attempts` (PK encounter+ordinal), `pokemon` (frozen rolls, origin,
  `source_encounter_id UNIQUE`, favorite, state), `inventory`, `candy`, `pokedex` (seen_at,
  caught_at), `reactions` (desired `add|remove`, actual `none|added`), `action_receipts`,
  `resource_ledger`, `sessions` (session_id PK, guild_id, user_id, profile_id NULL, revision,
  expires_at, selection). Indexes: `step_events(profile_id, created_at)`,
  `encounters(profile_id, state, created_at)`.
- `contracts/persisted-state.md` (C3): invariants — unresolved encounters (`queued` or
  `revealed`) per profile ≤ 3; meters in hundredths; receipts unique by key; secure delete;
  UUID profile ids never reused; restrictions keyed by (guild_id, user_id), never by profile.
