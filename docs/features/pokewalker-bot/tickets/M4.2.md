**Goal.** `pokewalker/bot/mod.py`: `app_commands.Group("walker-mod",
default_permissions=moderate_members, guild_only=True)`, inline SQL as admin_channels.py:

- `authorize`: guild, `guild_permissions.moderate_members`, actor not excluded —
  rechecked on every subcommand.
- Changes (`pause member duration? reason`, `resume`, `exclude`, `include`, `share-ban`,
  `share-unban`): one writer job that upserts `restrictions(guild_id,user_id)` (row may
  not exist — no profile needed, D28) and inserts `mod_audit(target_kind='user', action,
  reason)` together; blank reason refused. Pause `duration` is a `Choice`: indefinite
  (`paused_until NULL`), 1h, 24h, 7d; resume → `paused=0, paused_until NULL`. No handler
  touches `inventory`, `candy`, `pokemon` or `profiles.stardust`.
- Reads (`status member`, `log member?`): writer-serialized read jobs, no audit, no
  reason. Status: enrolled/paused(until)/excluded/share-banned, steps credited last hour
  and total (Σ `awarded_c`/100 from `step_events` by `created_at`), words discarded last
  hour (Σ `discarded_words`), queue size, catches (`catch_attempts.success=1`), last 5
  audit actions. Log: last 25 `mod_audit` rows of the guild, filtered by target when
  given; `<#channel>`-style ids only, never content. Replies suppress mentions.
- Register in `client.py` (one line); append C5.
