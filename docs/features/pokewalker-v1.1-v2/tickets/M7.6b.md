**Goal.** `bot/gyms.py` (extend) only:

- `gym_battle` (from `gym_view` of another's gym): saves `{gym_id, deployment_id, party: [],
  slot: 1, offset: 0, nominee: null}` in the selection — `deployment_id` is the defender shown.
- Party screen (5 rows max): row 0 **Prev**/**Next**/**Back**; row 1 one select of the current
  page of owned Pokémon (10 per page, CP/types, ineligible marked) filling the active slot;
  row 2 **Slot 1/2/3** buttons choosing the slot to fill (slot 1 required, distinct Pokémon);
  row 3 outcome select (**Clear only** / **Claim with slot n**); row 4 **Start** (disabled until
  valid). Values must be on the current page.
- `gym_battle_start` → `gyms.battle(..., selection.deployment_id, ..., now=walker.clock())` →
  result screen:
  outcome, defender sprite as thumbnail, first attacker's sprite as image (D49), HP summary,
  survivors, ≤ 15 event lines, "Claimed by <name>" or "Gym cleared (cap)", **Battle log** (full
  events, text), **Back**. `stale` or `cooldown` re-renders the party screen with a notice; no
  fight.
- Append C5; `content/help.md` one line.
