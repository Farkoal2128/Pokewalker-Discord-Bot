**Goal.** `pokewalker/services/raids.py` (new):

- `expire(conn, now, guild_id=None)`: for unended spawns with `expires_at <= now` (one guild or
  all): delete their `queued`/`revealed` raid encounters, delete their `raid_participation`
  rows, set `ended=1`; returns counts. The only expiry code (M8.4 schedules it).
- `spawn(conn, session, now, rng, content, checked_channel_id)` under receipt
  `wlt:<session>:<rev>`: owner/session/excluded; an authorized receipt returns its saved spawn
  (replay never hits `missing`/`active`); then `expire(conn, now, guild_id)` (an expired spawn
  awaiting the sweep never blocks a ticket; `/raid` agrees);
  `raids_enabled` else `raids_off`; `raid_channel_id` else `no_channel`; `checked_channel_id is
  None` → `no_permission`; **`raid_channel_id != checked_channel_id` → `channel_changed`**; an
  unended spawn → `active`; ticket held else `missing`. Refusals keep the ticket. Success:
  consume 1; insert `world_spawns(channel_id=checked_channel_id, post_state='pending',
  expires_at=now+3600, spawned_by_profile_id)`; ledger `wlt_use`.
- `nonce(spawn_id) = spawn_id.replace("-", "")[:25]` (Discord nonce ≤ 25 chars; API docs,
  unverified offline).
- `announce(bot, spawn)`: job `attempted` → `bot.get_channel(int(spawn.channel_id)).send(embed,
  nonce=nonce(spawn_id), allowed_mentions=none)` → job `sent` + message id; a failure after the
  send started leaves `attempted` (never retried); never re-reads the guild's channel.
- `resume_pending(bot)`: unexpired `pending` → `announce` once; `attempted` untouched.
- Append C3 (`post_state`, stored channel, expiry) and C5 (D2 exception: one embed, no pings).
