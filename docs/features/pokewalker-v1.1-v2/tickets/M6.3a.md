**Goal.**

- `services/storage.py` `identify`: after `identities` and their varieties, search
  `content.get("evolution_targets", [])` (≤ 3 lines); every caller (§3 list) then shows it.
- `services/evolution.py` (new):
  - `options(content, pokemon) -> [edge]`: edges from the Pokémon's identity whose `gender` is
    null or equals `pokemon["gender"]` (both the stored strings, M6.1a); one per `edge_id`.
  - `quote(conn, profile_id, pokemon_uid, edge_id, content, multipliers) -> {edge_id, target,
    cp_before, cp_after, candy_cost, candy_have, item, item_have, affordable}`; `cp_after` uses
    the target variety (gender variety by the Pokémon's gender), same IVs and `level_x2`.
  - `evolve(conn, session, pokemon_uid, edge_id, expected_revision, content, multipliers, now)`
    under `with_receipt(f"evolve:{uid}:{rev}", "evolve", ...)`, order as powerup.py:44-58:
    owner + exclusion → an authorized receipt returns its saved result (the evolved Pokémon no
    longer lists the edge) → `state='owned'`, revision, `edge_id` in `options`, costs; else
    `stale|excluded|insufficient|invalid`, nothing written. Success:
    `UPDATE pokemon SET pokemon_id=<target variety>, revision=revision+1` (uid, IVs, level, shiny,
    gender, favorite, caught_at, origin unchanged); candy −cost; **that edge's** item −1 when
    required; pokedex caught upsert for the target species; `check_and_award`; ledger `evolve`.
- Append C3 (evolution transition; receipt action `evolve`).
